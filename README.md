# Калькулятор ИБП и LFP АКБ

Статический сайт на HTML, CSS и JavaScript. Сборка не требуется.

Расчёт выполняется в браузере. Пользовательские данные не отправляются на сервер. Нет регистрации, базы данных, внешних API и ИИ-ассистента.

## Состав проекта

- index.html – форма и структура страницы.
- style.css – оформление калькулятора и редактора.
- calc.js – проверка каталога и расчёт без обращения к странице.
- app.js – загрузка каталога, форма, карточки и копирование.
- catalog.json – оборудование, цены и параметры расчёта.
- catalog-tool.html – редактор цен, проверка JSON и контрольные примеры.
- README.md – инструкция.

Все файлы должны находиться в корне репозитория.

## Первый запуск на компьютере

Сохраните содержимое каждого блока в файл с соответствующим именем. Используйте обычный текстовый редактор и кодировку UTF-8.

Не включайте в файлы строки с тройными обратными кавычками.

Проверьте, что файл называется index.html, а не index.html.txt.

Откройте index.html в браузере. При запуске с компьютера браузер может запретить автоматическое чтение catalog.json. В таком случае выберите catalog.json через поле ручного выбора на странице.

На опубликованном HTTPS-сайте каталог загружается автоматически.

## Работа с мастер-каталогом

Источник оборудования – предоставленный json_catalog.docx. Имя исходного XLSX в meta.source является справочной информацией. Калькулятор не читает XLSX.

Документ содержит текст JSON. Для импорта скопируйте только JSON, начиная с открывающей фигурной скобки и заканчивая закрывающей.

Откройте catalog-tool.html. Разверните блок изменения характеристик, вставьте JSON и нажмите "Применить JSON".

Редактор не распаковывает бинарный DOCX. Он исправляет артефакты экранирования квадратных скобок и подчёркиваний из предоставленного текстового представления.

Числа записываются без разделителей тысяч и с десятичной точкой. Значения true, false и null записываются без кавычек.

Пустые паспортные значения не следует заменять нулём. Используйте null там, где предусмотрено отсутствие данных.

Для синхронизации с DOCX после обновления скопируйте проверенный JSON из редактора обратно в мастер-документ.

## Обновление цен без изменения программы

Откройте опубликованный catalog-tool.html. Измените цены в таблице.

Укажите дату для отдельных записей. Если дата записи пустая, используется дата цен по умолчанию. Не изменяйте общую дату, если обновилась только часть цен.

Нажмите "Проверить каталог". Ошибки необходимо исправить. Предупреждения не исключают записи, но требуют проверки исходных характеристик.

Нажмите "Скопировать catalog.json". Откройте catalog.json в GitHub, нажмите кнопку редактирования и замените всё содержимое скопированным JSON.

Подтвердите изменение кнопкой Commit changes. Cloudflare Pages автоматически запустит новую публикацию.

Редактор не сохраняет изменения на сервере. Если закрыть вкладку до копирования и публикации, изменения будут потеряны.

## Добавление ИБП

В блоке JSON скопируйте похожую запись из массива ups. Добавьте её в тот же массив и измените характеристики.

Между соседними объектами должна быть запятая. После последнего объекта запятая не нужна.

SKU должен быть непустым и не повторяться среди ИБП и АКБ. Модель и серия обязательны.

Мощности ratedKw и ratedKva задаются в кВт и кВА. outputPF – коэффициент мощности выхода. Не путайте его с коэффициентом мощности нагрузки.

Фазность задаётся числами 1 или 3. maxParallel задаётся целым числом допустимых ИБП в группе.

Для разрешённой производителем пофазной установки укажите allowPerPhase = true.

Назначение типов АКБ следующее.

- builtin – встроенная АКБ без расширения.
- external – ИБП без встроенной АКБ.
- builtin+external – встроенная АКБ с внешним расширением.

Для builtin укажите положительную builtInEnergyKwh и maxExternalBatteriesPerUps = 0.

Для external укажите builtInEnergyKwh = 0, серию compatibleBatterySeries и положительный предел внешних АКБ на один ИБП.

Для builtin+external укажите положительную встроенную энергию и параметры внешнего расширения.

batteryVoltageV – напряжение аккумуляторной шины.

Допустимые значения topology – line-interactive и double-conversion. Топология отображается, но не фильтрует подбор.

enabled = false отключает запись. showPrice = false скрывает цену, исключает вариант из выбора минимальной стоимости и отключает проверку бюджета для него.

## Добавление внешней АКБ

Скопируйте похожую запись в массиве batteries и измените её поля.

Для совместимости series батареи должна совпадать с compatibleBatterySeries ИБП без учёта регистра и крайних пробелов. Напряжения должны совпадать.

chemistry задаётся как LFP. energyKwh должна быть больше 0.

capacityAh – паспортная ёмкость. maxDischargeA – паспортный предел тока одного модуля. Если значение неизвестно, оставьте null.

dodPct можно оставить null для использования значения по умолчанию. Допустимый диапазон указанного DoD составляет 50–100 %.

Батареи соединяются только параллельно. Последовательные цепочки и смешанные банки из разных моделей не подбираются.

Для оценки времени заряда при отсутствии А·ч используется энергия, делённая на напряжение. Это расчётная оценка, не замена паспортной ёмкости.

## Добавление готового комплекта

Добавьте отдельную запись ИБП с собственной моделью, SKU и ценой.

В kitOf укажите sku составляющего ИБП и count блоков. Пример текстового значения состава – два блока с SKU cpw C 6-5.

Номинальная мощность и встроенная энергия комплекта задаются для всего комплекта. maxChargeCurrentA указывается согласно принятому представлению одной товарной позиции комплекта в каталоге.

При совпадении состава и выходной фазности группа без внешних АКБ заменяется комплектом. Используется цена комплекта. Повторная конфигурация с тем же составом не показывается.

При замене группы электрические показатели рассчитываются по составляющим блокам. При непосредственном подборе комплектной записи используются её паспортные поля.

Поэтому характеристики комплекта и составляющих должны быть согласованы, особенно ток заряда, напряжение, встроенная энергия и КПД.

## Параметры расчёта

Раздел params содержит значения по умолчанию и правила подбора.

Для изменения начального запаса мощности используйте powerReservePct. Для начального тока заряда – defaultChargeCurrentA.

agingReservePct увеличивает необходимый энергетический запас.

recommendedCapacityMandatory включает обязательное достижение рекомендуемой ёмкости. При выключенном параметре недостаток рекомендуемой ёмкости даёт предупреждение.

recommendedCapacityForSingleUps распространяет правило рекомендуемой ёмкости на один ИБП.

growUpsCountForBuiltInEnergy разрешает увеличивать количество ИБП со встроенными АКБ для достижения автономии.

maxChargeTimeH задаёт максимальную допустимую верхнюю границу времени заряда. null отключает ограничение.

replaceGroupWithKit включает замену совпадающей группы комплектом.

allowSinglePhaseUpsPerPhase разрешает пофазные схемы. phaseUnbalanceFactor задаёт коэффициент неравномерности для расчёта одной фазы.

## Принятые инженерные допущения

Для пофазной схемы нагрузка одной фазы рассчитывается как треть общей нагрузки, умноженная на phaseUnbalanceFactor.

У моделей, поддерживающих параллельную работу, в пофазной схеме предполагается общий внешний банк на всю систему. Расчёт на фазу является эквивалентным распределением банка. Возможность такой DC-схемы нужно подтвердить у производителя.

Для остальных моделей у каждой фазы свой внешний банк.

Наличие allowPerPhase не доказывает возможность питания трёхфазного двигателя. При трёхфазных потребителях выводится предупреждение о синхронной работе.

Ток разряда проверяется по постоянной активной нагрузке для ИБП с внешними АКБ. Пусковой ток проверяется отдельно по полной мощности и перегрузочной способности ИБП, без исключения варианта.

Распределение тока между встроенной и внешней АКБ для builtin+external не моделируется.

Нижняя граница времени заряда определяется установленным током с ограничением паспортным током ИБП. Верхняя определяется дополнительным ограничением 0,3C. Если установленный ток ниже 0,3C, границы совпадают.

Время заряда считается по полезной энергии с коэффициентом дозаряда из params. Паспортный максимальный зарядный ток самой АКБ в исходном каталоге отсутствует, поэтому быструю границу нельзя считать гарантированной.

При восстановлении сети расчёт вводного тока предполагает одновременное питание нагрузки и заряд всех АКБ максимальным установленным током.

Требуемая выделенная мощность по автомату рассчитывается как напряжение, умноженное на номинал автомата. Для трёхфазной сети дополнительно применяется квадратный корень из трёх. Это ориентир по токовой пропускной способности, а не подтверждение доступной мощности по договору энергоснабжения.

Выбор автомата не заменяет проверку кабелей, селективности, характеристик расцепителя, токов короткого замыкания и условий установки.

## Контрольные примеры

Откройте catalog-tool.html и нажмите "Проверить контрольные примеры".

Проверки используют изолированные пары оборудования из открытого каталога. Они не изменяют каталог и не сравнивают всю выдачу, поскольку в полной выдаче другая модель может выиграть по цене.

Проверки рассчитаны на исходные параметры предоставленного каталога. После изменения параметров ожидаемые результаты могут измениться.

При нагрузке 1 кВт, автономии 60 мин, запасе мощности 25 % и токе заряда 30 А для пары cpu-e5 и cpu-b51100 ожидается один ИБП и одна АКБ.

Требуемая энергия составляет примерно 1,221 кВт·ч. Расчётная автономия составляет 245,7 мин, отображается как 4 ч 00 мин. Стоимость оборудования составляет 265000 руб. Вводной автомат составляет 16 А, выделенная мощность по нему составляет 3,68 кВт.

При нагрузке 5 кВт, времени 1 мин и запасе мощности 0 % этой же паре нужны две АКБ по допустимому току разряда.

При нагрузке 8 кВт, времени 60 мин и запасе 25 % нужны два e5 и два b51100. Автономия составляет 61,425 мин. Выводится предупреждение о рекомендуемой ёмкости 800 А·ч на группу.

При трёхфазном вводе 400 В, нагрузке 9 кВт и времени 60 мин для этой пары ожидаются три ИБП и три АКБ, автономия 81,9 мин.

При нагрузке 500 Вт и цели 120 мин PowerUnit i1 не обеспечивает цель. Расчётная автономия составляет 58,968 мин.

Дополнительно проверяются бюджет, повтор SKU и правила округления автономии.

Это контрольные проверки расчётного ядра. Они не заменяют ручную проверку интерфейса и инженерную приёмку.

## Подключение Cloudflare Pages

В панели Cloudflare откройте раздел Workers & Pages и создание проекта Pages с подключением Git-репозитория.

Авторизуйте интеграцию GitHub и выберите репозиторий 71sky/ups-calculator-mvp. API-токен для этого проекта не требуется.

Укажите следующие настройки.

- Project name – ups-calculator-mvp.
- Production branch – ветка, в которую загружены файлы, обычно main.
- Framework preset – None.
- Build command – оставить пустым.
- Build output directory – корень репозитория, обычно поле /.
- Root directory – оставить пустым.

Запустите публикацию.

Публичный адрес ожидается в виде https://ups-calculator-mvp.pages.dev. Точное имя зависит от доступности имени проекта и результата публикации. Наличие этой ссылки само по себе не означает, что сайт уже развёрнут.

После публикации откройте страницу и проверьте загрузку каталога, контрольные примеры и копирование результата.

## Проверка перед использованием

- На странице доступны 28 ИБП и 6 АКБ исходного каталога.
- В проверке каталога нет ошибок, предупреждения изучены.
- Отрицательная нагрузка и нулевое время дают сообщения у полей.
- При смене сети подставляются 230 или 400 В.
- Бюджет исключает варианты с превышением известной стоимости.
- При недостаточной автономии показано явное несоответствие.
- Готовый комплект и совпадающая группа не дублируются.
- Копирование содержит исходные данные и все показанные карточки.
- На смартфоне форма и карточки читаются без горизонтальной прокрутки.
- Все контрольные примеры исходного каталога проходят.

## Обновление сайта

Для изменения цен обычно достаточно заменить catalog.json в GitHub.

Для изменения оформления редактируйте style.css. Для изменения формул требуется инженерная проверка изменений calc.js.

После каждого коммита в производственную ветку Cloudflare Pages автоматически публикует новую версию при подключённой Git-интеграции.

Если публикация завершилась, но браузер показывает старую версию, выполните принудительное обновление страницы.

Для возврата старых цен используйте историю catalog.json в GitHub и восстановите предыдущую редакцию новым коммитом.

## Ограничения текущей версии

Программа не проверяет коммерческую доступность оборудования и актуальность ссылок через интернет.

Производитель Coway указан на основании названия предоставленного каталога. Мультибрендовый подбор не предусмотрен.

Не подбираются кабели, стойки, предохранители DC, коммутация, байпас и дополнительные интерфейсные модули.

Пофазные ограничения трёхфазных ИБП, зависимость КПД от нагрузки, низкотемпературный заряд и динамические ограничения BMS не представлены исходными данными.

Не следует использовать расчёт как готовый проект электроснабжения.
